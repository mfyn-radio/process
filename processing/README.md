# MFYN Processing sketches

Three sketches, set up and run the same way (Processing 4; the Reel and Album sketches also need ffmpeg):

- `MFYN_Reel/`: one track in, one white dot-matrix radio Reel out (discovery, automated).
- `MFYN_Album/`: one album folder in, one media-player Story out (featured album, posted with the Bandcamp link; automated by Make Album Story).

- `MFYN_Archive/`: one episode number and date in, one orange archive cover out (1080×1080 PNG). The brand anchor: kept independent of the other two so its look stays fixed.

Each folder has its own README with setup, inputs and settings.
Open a sketch by double-clicking its main `.pde` file (MFYN_Reel.pde / MFYN_Album.pde / MFYN_Archive.pde).

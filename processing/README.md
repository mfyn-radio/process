# MFYN Processing sketches

Two sketches, set up and run the same way (Processing 4 + ffmpeg):

- `MFYN_Reel/`: one track in, one orange dot-matrix radio Reel out (discovery, automated).
- `MFYN_Album/`: one album folder in, one media-player Story out (featured album, posted with the Bandcamp link).

Each folder has its own README with setup, inputs and settings.
Open a sketch by double-clicking its main `.pde` file (MFYN_Reel.pde / MFYN_Album.pde).
